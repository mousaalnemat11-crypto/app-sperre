# App-Sperre
1. Repo auf GitHub erstellen, alle Dateien hochladen (inkl. Ordner .github).
2. Tab "Actions" -> "Build APK" -> fertig gebaut -> unten bei "Artifacts" die APK laden.
3. APK installieren und App öffnen. Voreingestellt sind die Kontakte ماما und بابا.
4. "1. Löschschutz aktivieren" -> Aktivieren bestätigen.
5. "2. Sperre aktivieren" -> Bedienungshilfen -> App-Sperre einschalten.
Wichtig: Erst Schritt 1 und 2, dann ist die App in den Einstellungen nicht mehr erreichbar.
